# Regole del Progetto FireMageHUD-335

## Scorciatoie e Comandi Utente

### Comando `CP` (Commit & Push)
Quando l'utente scrive **`CP`** (oppure "cp", "fai CP"):
1. Significa **Git Commit + Git Push**.
2. Esegui subito:
   - `git status`
   - `git add -A` (o i file di progetto modificati)
   - `git commit -m "..."` con un messaggio chiaro, descrittivo e professionale in italiano che riassuma le modifiche fatte
   - `git push origin main`
3. Fornisci un breve riscontro all'utente confermando l'hash del commit e il push avvenuto.
